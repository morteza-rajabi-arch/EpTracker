# EpTracker 📱

**An offline-first Android app for tracking your entertainment and reading progress.**

EpTracker is a personal media tracker designed to help you organize your favorite series, anime, movies, books, and manga in one place.

## ✨ Features

* 📚 Track different types of media.
* 📊 Keep track of your viewing and reading progress.
* 📁 Organize content into folders.
* 🌙 Enjoy a customizable dark and light theme.
* 🔒 Store your data locally on your device.
* 📶 Access your library offline.

## 🛠️ Tech Stack

* **Language:** Kotlin
* **UI:** Jetpack Compose
* **Database:** Room
* **Architecture:** MVVM

## 🚧 Project Status

EpTracker is currently under development. More features and improvements are planned.

## 🎯 Goal

To build a clean, user-friendly, and reliable Android application for managing personal media libraries and tracking progress.
